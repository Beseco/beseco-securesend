Cloud-Anbieter hinzufügen

Gilt für Nextcloud und ownCloud (WebDAV und OCS-Freigaben). Als Server-URL die Basis der Installation eintragen — bei ownCloud oft mit Unterpfad, z. B. https://nas.example.com/owncloud (nicht nur die Domain, wenn die Instanz in einem Unterordner liegt).
Hinweis: App key und ggf. App secret aus der Dropbox App Console (dieselbe App wie beim OAuth-Flow). PKCE-Apps haben oft kein Secret — Feld leer lassen. Refresh-Token: entweder nur den refresh_token-String oder die gesamte JSON-Antwort vom Token-Endpunkt (wird erkannt). Voraussetzung: Flow mit token_access_type=offline. Nicht der Code aus der Browser-URL, nicht nur access_token. Browser-Passwortmanager: Felder unten können falsche Daten eintragen — ggf. prüfen. OAuth Guide.
HiDrive (Strato): Benutzername und Passwort Ihres Strato HiDrive-Kontos.
Synology: Als NAS-URL die Adresse von DSM eintragen (Web-API), z. B. https://192.168.1.10:5001 oder https://nas.example.com:5001 — keine reine QuickConnect-Weiterleitung ohne erreichbare /webapi/-Pfade. Paket File Station installieren; für Uploads WebDAV aktivieren. Hinter einem Reverse-Proxy muss /webapi/auth.cgi JSON liefern, keine HTML-Anmeldeseite.
MinIO (S3-kompatibel): Eigener SecureSend Storage. Alternativ auch AWS S3 nutzbar.
SecureSend Storage ist der von SecureSend bereitgestellte Speicher für Ihre Sendungen: Dateien liegen in der SecureSend-Infrastruktur, Sie hinterlegen keine Zugangsdaten zu einem externen Cloud-Dienst. Abruf erfolgt nur über die Anwendung und die verschickten Links — nicht wie bei einer öffentlichen Ordnerfreigabe.
